# Flappy Clone

A simple Flappy Bird–style game that runs in the browser. It's plain HTML, CSS and JavaScript with no install or build step.

## How to play

Open `index.html` in a browser. Press **Space** (or the up arrow), click, or tap to flap. Fly through the gaps in the pipes. Each pipe you pass scores a point, and your best score is saved in your browser.

## Files

- `index.html`: the page and the `<canvas>` the game draws on
- `style.css`: page styling
- `script.js`: all the game logic (physics, pipes, scoring, drawing)

## Tweaking the game

The constants at the top of `script.js` control how it feels. Try changing `GRAVITY`, `FLAP_STRENGTH`, `PIPE_SPEED` or `PIPE_GAP`.
